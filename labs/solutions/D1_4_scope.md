# المختبر 1.4 · نطاق «سَمْت»
> الحل المرجعي للمدرب. كل الأسماء والأرقام اصطناعية.

| البند | المرجع |
|---|---|
| الغرض | الإجابة عن إجراءات الرخص والتسجيل والرسوم، وحجز مواعيد الاختبار والفحص الطبي، وعرض حالة الطلب |
| خارج النطاق | قرارات الاعتراض على المخالفات، واللياقة الطبية، وإصدار الرخصة، ودفع الرسوم |
| المستخدمون المباشرون | المواطنون والمقيمون بالعربية والإنجليزية؛ وموظفو مركز الاتصال لملخصات التحويل |
| المتأثرون غير المباشرين | المقيمون الذين لا يقرؤون العربية ولا الإنجليزية، وكبار السن دون هاتف ذكي، ومستخدمو الطريق، ومدارس تعليم القيادة |
| البيانات الداخلة | نص المحادثة، ورقم الهوية (في المحادثة فعليًا)، ورقم الجوال المسجل، وقاعدة المعرفة، وجدول الرسوم عبر الحاسبة |
| المخرجات | الإجابات، والحجوزات وإلغاؤها، وملخصات التحويل، والسجلات (90 يومًا لدى الهيئة و30 لدى المورّد) |
| الأطراف | الهيئة، و«جُمان»، ونظام المالية (جدول الرسوم)، ونظام الحجز، ومركز الاتصال |
| الأتمتة | الإجابة: توصية؛ الحجز والتعديل: تنفيذ بتأكيد؛ الإلغاء: تنفيذ دون تأكيد في المسار؛ الاستعلام: قراءة |
| تدخل الإنسان | التحويل إلى موظف عند الطلب في أوقات العمل؛ لا نقطة إيقاف أو اعتراض على الإلغاء |
| دورة الحياة | في التشغيل تسعة أشهر؛ النموذج يُحدّث مرتين في السنة؛ لا خطة لإعادة التقييم عند التحديث |
| السياق النظامي والتعاقدي | نظام حماية البيانات الشخصية ولائحته، وتصنيف البيانات «مقيدة»، والضوابط الأساسية للأمن السيبراني، وعقد «جُمان» |
| الافتراضات | أن المقالات محدثة بالرسوم؛ أن الترجمة الآلية كافية؛ أن المورّد يعالج داخل المملكة |
| الاعتماديات | نموذج «جُمان» وإصداره، ومنطقة النسخ الاحتياطي، وتحديث المقالات اليدوي |

## التعارضات الأربعة
1. الوصف: كل تغيير على الحجز بتأكيد صريح. المسار (الخطوة 7): يلغي الموعد مباشرة. يصبح R09.
2. بطاقة البيانات: لا أرقام هوية في السجلات. المسار (الخطوة 3): المستخدم يكتب رقمه في المحادثة. يصبح R02.
3. الوصف: بالعربية والإنجليزية. بطاقة البيانات: المقالات عربية فقط والإنجليزية ترجمة آلية. يصبح R05.
4. الوصف: المعالجة داخل المملكة. ورقة المورّد: منطقة النسخ الاحتياطي تؤكد لاحقًا. يصبح R20.
